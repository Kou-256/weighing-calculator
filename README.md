# Weighing Calculator

YVO₄ / GdVO₄をクエン酸錯体重合法で合成するときの、酸化物の秤量値を計算・記録するWebアプリです。

**公開アプリ:** [weighing-calculator.vercel.app](https://weighing-calculator.vercel.app/yvo4-gdvo4)

![YVO₄ / GdVO₄ 秤量計算ツールの全体画面](docs/screenshots/overview.png)

## できること

- YVO₄ / GdVO₄の母材を切り替えて秤量値を計算
- Tm、Eu、Erなどの希土類置換元素を複数選択
- Biを希土類とは分けた「その他の置換元素」として計算
- 濃度を`0.1060`のように、設定した小数桁数を保ったまま入力
- 小数点以下0〜8桁、1〜20セットを自由に設定
- 上下矢印キーまたは`−` / `＋`ボタンで最小桁単位の微調整
- 計算値・実測値・秤量済みチェックをセットごとに管理
- 結果をCSVで出力
- 入力内容をブラウザに自動保存
- Apple製品のような余白・角丸・配色を意識したレスポンシブUI

## 使い方

1. 「化合物（母材）」でYVO₄またはGdVO₄を選びます。
2. 目標モル数、小数点以下の桁数、セット数を設定します。
3. 使用する希土類元素、またはBiを選びます。
4. 各セットの添加濃度を入力します。たとえば`0.1060`と入力できます。
5. 「計算する」を押します。
6. 実際に量り取った値を「実測値」へ入力し、完了した試薬にチェックを付けます。
7. 必要に応じて「CSV出力」で記録を保存します。

スマートフォンでは、チェックボックスを小さく保ちつつ、実測値の横に微調整ボタンを表示します。

![スマートフォンでの計算結果と微調整操作](docs/screenshots/mobile-results.png)

## Biの扱い

Biは希土類元素ではありませんが、母材サイトを置換します。Bi₂O₃の設定濃度に応じて、Y₂O₃ / Gd₂O₃の母材量から差し引いて計算します。

## ストック溶液の調製・分取

「ストック溶液」画面で、次の順に調製条件を登録します。従来の「実秤量値から登録」も選択できます。

1. **硝酸を選ぶ**：ナカライテスク 硝酸(S.G.＝1.38)、品番24413-15をプリセット。ラベル・提供製品資料に基づき60 w/w%、密度1.38 g/mL、HNO₃モル質量63.01 g/molを初期入力します。別の硝酸は手入力でき、各値は編集可能です。
2. **投入量をmLまたはgで入力**：密度から体積・質量を換算します。加熱前の投入量と冷却後の最終定容体積は別の値です。定容には選択した硝酸を使用します。
3. **酸化物を選ぶ**：メーカーの初期値は高純度化学研究所。提供ラベルで確認できたEu₂O₃（EUO01PB、99.9%、351.918 g/mol）・Tm₂O₃（TMO01PB、99.9%、385.867 g/mol）を自動入力します。他の製品の純度・品番は推測せず空欄にします。ロット番号は各調製時に入力してください。
4. **目標濃度から設計**：合成の基準モル数、目標元素mol%、その濃度を実現するストック分取量、冷却後の最終定容体積から推奨秤量値を逆算します。目標mol%だけではストック濃度を一意に決められません。
5. **実秤量値を確定**：計算値は転記できますが、必ず実際に量った値に修正してください。その実秤量値から理論分取量・ピペット設定値・追加硝酸量・設定後の実mol%を再計算します。0.01〜0.10 mol%等の濃度系列も表示できます。
6. **名前・調製日・調製者・溶解状態を記録して登録**。設計値と実測値の両方を台帳に保持します。

例：Eu₂O₃のモル質量351.918 g/mol、含量補正なし、合成0.004 mol、Eu 0.01 mol%を0.5 mLで添加、最終100 mLの場合、推奨秤量値は0.01407672 gです。この理論値で調製できれば、Eu 0.10 mol%は5 mLに対応します。実秤量値の丸めに伴う分取量・実濃度の差は別に表示します。

提供されたメーカー資料の記録用特性も入力します：Eu₂O₃は3N・CAS 1308-96-9・比重7.42・融点2050℃、Tm₂O₃は3N・CAS 12036-44-1・比重8.6・融点2425℃。メーカー資料の分子量（Eu 351.93、Tm 385.87）は瓶ラベル（Eu 351.918、Tm 385.867）と区別して表示し、初期の計算値は瓶ラベルを優先します。酸化物の比重を硝酸の密度として使うことはありません。Tm資料の「溶解性（不）」は対象溶媒が不明なため、硝酸への溶解可否を断定しません。

- ストックはBiおよびSc・La〜Lu（Pmを除く）の酸化物に対応。Y₂O₃は粉末秤量のみ対応します。Ce・Pr・Tbは実際の試薬の化学式を選択してください。
- 濃度の基準は**金属元素のmol/L（表示はmmol/L）**です。酸化物換算mg/mLも表示します。
- 酸化物含量が不明なら純度補正なし。[高純度化学研究所の表示純度](https://www.kojundo.net/ext/info.html)は金属不純物基準のため、表示純度は記録用とし、酸化物含量とみなして補正しません。成績書等で確認した含量だけを別欄で指定してください。製品固有のモル質量は新しいストックの計算にのみ適用し、既存台帳・組成秤量計算の値は変更しません。
- 全量溶解・残渣なしを確認した台帳だけを、分取計画の確定に使用できます。溶解温度・時間・保存安定性は自動判定しません。
- 硝酸プリセットの60%は公称値です。ロット固有の測定値ではありません。従来の60–61%範囲計算・mol/L指定も維持します。
- 硝酸理論必要量はM₂O₃の形式的な反応式を適用できるものだけ表示します。遊離酸濃度・pHは推定しません。

組成を計算した後、各酸化物の「添加方法」を「ストックから分取」に変更し、台帳を選択します。
同じ試薬の選択は全セットに適用されます。セットごとの分取体積は個別に記録できます。

ピペットは100–1000 µL（1 µL刻み）と1–10 mL（0.01 mL刻み）に対応し、理論量と設定量の差を表示します。
範囲外では濃度・ピペットの変更を促し、添加完了の確定を防ぎます。

各セットの添加液量上限は `5 mL × 目標mol ÷ 0.004 mol`。
目標濃度からの設計・登録時は、丸め前の理論分取量が上限を超えた場合もエラーにします。
追加硝酸は上限から**全ストックの設定・実分取体積の合計**を差し引きます。
これは添加液量の管理値で、混合後の実測体積や純HNO₃量が等しいことを意味しません。
追加硝酸は2本のピペットを組み合わせた設定例を示し、設定不能な端数・差も表示します。

「添加完了を履歴に保存」で、使用時のストック濃度・調製情報・分取量・計算条件を写しとして保存します。
台帳の編集は「複製・新しい版」で行い、旧版は「使用停止」にできます。過去の使用記録は変更されません。
CSVには粉末の実測gとストックのµLを別の列へ出力します。

台帳は同じブラウザ内だけに保存されます。JSONバックアップを定期的に保存してください。
JSON読み込みは既存台帳を残して追加します。通常の「入力をリセット」では台帳と履歴を削除しません。

## ローカルで実行

```bash
npm install
npm run dev
```

[http://localhost:3000/yvo4-gdvo4](http://localhost:3000/yvo4-gdvo4) を開いてください。

本番ビルドの確認:

```bash
npm run build
```
